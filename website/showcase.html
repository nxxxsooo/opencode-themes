Inline Formatting

Text Formatting

This is regular paragraph text in the OpenCode theme. The font stack uses PingFang SC for beautiful CJK rendering, with a comfortable 1.8 line height.

Here is bold text styled in gold to make it stand out. And here is italic text in purple for emphasis. You can also use strikethrough for deleted content.

Highlighted text uses a warm amber background that catches attention without being harsh.

You can combine them: bold italic, or even bold italic strikethrough.

JavaScript

// OpenCode theme configuration
const theme = {
  name: "OpenCode",
  variant: "dark",
  colors: {
    background: "#0d1117",
    foreground: "#f0f6fc",
    accent: "#8a6cc4",
    headings: "#d19af8",
  },
};

async function loadTheme() {
  const css = await fetch("opencode.css");
  console.log(`Loaded: ${theme.name}`);
  return css.text();
}

Python

# Color palette extraction
from dataclasses import dataclass

@dataclass
class OpenCodePalette:
    bg_primary: str = "#0d1117"
    purple: str = "#d19af8"
    gold: str = "#e5a030"
    cyan: str = "#5fd4bb"

    def to_css_vars(self) -> str:
        return f"""
:root {{
  --bg-primary: {self.bg_primary};
  --purple: {self.purple};
  --gold: {self.gold};
}}"""

palette = OpenCodePalette()
print(palette.to_css_vars())

Math (LaTeX)

Math Blocks

OpenCode styles both inline and block math. Here's Euler's identity rendered in a block:

eiπ + 1 = 0

And the quadratic formula:

x = (−b ± √(b² − 4ac)) / 2a

Inline math like E = mc² uses the same monospace styling as code.

Footnotes

Footnotes

The OpenCode theme was originally created for Obsidian[1] and later ported to Typora[2]. It draws inspiration from the Tokyo Night color scheme[3].

[1] Obsidian is a knowledge management app. obsidian.md

[2] Typora is a minimal markdown editor. typora.io

[3] Tokyo Night originated as a VS Code theme by enkia.
